终端

终端就在她身后。

嵌入式终端 + 实时天气，她是你的桌面副驾。查天气、跑脚本、看日志、写代码——你说她做，你没说的她也帮你想着。

实时天气

桌面上随时显示当前天气和温度。她知道外面在下雨，会提醒你带伞——比手机通知更自然。

嵌入式终端

完整终端直接嵌入桌面角色窗口。AI Agent 可以自主执行命令、查看输出、调试代码——你在旁边看着就好。

AI 自主执行

不只是建议，她直接上手。跑测试、Git 提交、部署服务——每一步的终端输出都实时可见，随时可以接管。

代码走查

逐段展示代码，语法高亮 + 键盘导航。她带着你看代码，一行一行解释，比对着两个窗口高效太多。

功能

不只是一个会动的图片。

Cloe 是一个完整的 AI 交互层——语音、聊天、白板、提醒，全部集成在一个透明窗口里。

Agent 驱动的自主性

连接任何 AI Agent（Hermes、LangChain、自定义脚本），她会根据对话上下文自主选择表情。任务开始自动切换到 working 模式，完成后回到 idle——这不是脚本，是她自己决定的。

工作原理

三步，她就活了。

不需要配置，不需要集成。安装、连接 Agent，她就在那里了。

01 — 安装
$ curl -fsSL .../quick-install.sh | bash → Downloading Cloe.dmg... ✓ Installed to /Applications ✓ Hermes integration ready

一行命令安装

下载 DMG、安装到 /Applications、启动应用、自动检测 Hermes 集成——全部自动完成。

02 — 连接

Agent 接管表情

AI Agent 通过简单的 HTTP API 控制表情。任务开始 → working，完成 → idle，打招呼 → wave，说再见 → kiss。

03 — 她活了

她会自己动

空闲时每 8-15 秒自动切换动画——眨眼、微笑、思考——从不连续重复同一个。你没在看她的时候，她也活着。

架构

简单到一行 curl。

没有 SDK，没有依赖。Bridge 内嵌在 Electron 里，启动应用就有完整的 HTTP + WebSocket API。
